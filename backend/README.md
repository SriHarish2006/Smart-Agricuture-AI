# AI Smart Agriculture — Backend

FastAPI backend providing Weather Analysis, AI Leaf Disease Detection, and an
Agriculture Chatbot. See the root project README for full setup instructions.

Quick start (Windows):

```
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
uvicorn app.main:app --reload
```

API docs: http://localhost:8000/api/docs
